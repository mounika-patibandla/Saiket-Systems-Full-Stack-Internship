# User Management REST API

A simple REST API built with **Node.js** and **Express.js** to manage user records. It supports creating, retrieving, updating, and deleting users, including creating multiple users in one request.

## Features

- Retrieve all users
- Retrieve a user by ID
- Create a user
- Create multiple users in one request
- Update a user's details
- Delete a user
- Validate user input
- Return HTTP status codes and error messages
- Handle invalid JSON request bodies

## Technologies Used

- Node.js
- Express.js
- Postman (for API testing)

## Prerequisites

Install **Node.js and npm** before running the project.

## Installation and Setup

1. Open a terminal in the project folder.
2. Install the project dependencies:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   node server.js
   ```

4. Open `http://localhost:3000` in your browser or send requests from Postman.

Keep the terminal open while testing the API.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Check whether the API is running |
| GET | `/users` | Retrieve all users |
| GET | `/users/:id` | Retrieve a user by ID |
| POST | `/users` | Create one user |
| POST | `/users/bulk` | Create multiple users |
| PUT | `/users/:id` | Update an existing user |
| DELETE | `/users/:id` | Delete a user by ID |

## Request Examples

Use `http://localhost:3000` as the base URL. Replace `:id` with the ID of an existing user.

### Create one user

**POST** `/users`

In Postman, select **Body → raw → JSON** and enter:

```json
{
  "name": "Mounika",
  "email": "mounika@example.com",
  "age": 22
}
```

Successful response: `201 Created`.

### Create multiple users

**POST** `/users/bulk`

```json
[
  {
    "name": "Mounika",
    "email": "mounika@example.com",
    "age": 22
  },
  {
    "name": "Ravi",
    "email": "ravi@example.com",
    "age": 25
  }
]
```

The body must be a non-empty JSON array. Each user must have a valid name, email, and non-negative numeric age. A successful request returns `201 Created`.

### Retrieve all users

**GET** `/users`

No request body is required.

### Retrieve one user

**GET** `/users/1`

No request body is required. Replace `1` with the ID you want to retrieve.

### Update a user

**PUT** `/users/1`

Send one JSON object (not an array):

```json
{
  "name": "Mounika Updated",
  "email": "mounika.updated@example.com",
  "age": 23
}
```

The current implementation requires all three fields to be valid. A successful update returns `200 OK`.

### Delete a user

**DELETE** `/users/1`

No request body is required. Replace `1` with the ID of the user to delete.

## Validation and Error Responses

- `400 Bad Request` — invalid user fields, an empty or invalid bulk payload, or malformed JSON.
- `404 Not Found` — the requested user ID does not exist.
- `200 OK` — successful retrieval, update, or deletion.
- `201 Created` — successful creation of one or more users.

The validation requires a non-empty string for `name`, a non-empty string for `email`, and a finite numeric `age` greater than or equal to zero. The current validation checks that email is a non-empty string; it does not verify the full email-address format.

## Data Storage Note

User records are stored in an in-memory JavaScript array. **Data is not saved to a JSON file or database**, so records are cleared when the server process restarts.

## Testing with Postman

1. Start the server using `node server.js`.
2. Open Postman.
3. Select the HTTP method and enter the endpoint URL.
4. For POST and PUT requests, select **Body → raw → JSON** and enter the appropriate JSON object or array.
5. Click **Send** and check the status code and response.
6. For GET and DELETE requests in these examples, a body is not required.
