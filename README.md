# Saiket Systems – Full Stack Development Internship

## About the Internship

This repository contains the six projects completed as part of my **Full Stack Development Internship at Saiket Systems**.

Throughout this internship, I worked on frontend development, responsive web design, JavaScript, React.js, backend development, REST API creation, database integration, and full-stack application development.

The internship helped me gain practical experience in developing web applications and understanding how frontend, backend, and databases work together.

## Internship Tasks

### Task 1: Static Portfolio Website with a Theme

**Description:**

Developed a static portfolio website with a homepage, Projects section, and contact form.

**Key Features:**
- Designed a portfolio homepage.
- Created a Projects section with project placeholders.
- Added a contact form with JavaScript validation.
- Focused on responsive and visually appealing design.

**Technologies Used:**
- HTML
- CSS
- JavaScript

### Task 2: Responsive Web Page

**Description:**

Created a responsive webpage using HTML, CSS, and Bootstrap/Tailwind concepts, with interactive features using JavaScript.

**Key Features:**
- Designed a responsive webpage.
- Implemented a landing page layout.
- Added interactive elements.
- Implemented form validation or toggle functionality.

**Technologies Used:**
- HTML
- CSS
- Bootstrap / Tailwind CSS
- JavaScript

### Task 3: Front-End Framework Basics – React.js

**Description:**

Developed a To-Do List application using React.js to understand the fundamentals of frontend frameworks.

**Key Features:**
- Add new tasks.
- Edit existing tasks.
- Delete tasks.
- Manage tasks through React components and state.

**Technologies Used:**
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Task 4: Build a Basic REST API

**Description:**

Developed a REST API using Node.js and Express.js to perform CRUD operations on a User entity.

**Key Features:**
- Create user records.
- Retrieve user information.
- Update user details.
- Delete user records.
- Test API endpoints using Postman / Thunder Client.

**Technologies Used:**
- Node.js
- Express.js
- JavaScript
- JSON
- Postman / Thunder Client

### Task 5: Database Integration

**Description:**

Worked on integrating a database with a REST API to store and retrieve user information.

**Key Features:**
- Learned basic SQL concepts.
- Established database connectivity.
- Stored user information such as name, email, and age.
- Retrieved user data using SQL queries.
- Integrated database operations with API endpoints.

**Technologies Used:**
- SQL
- Database
- Node.js
- Express.js
- JavaScript

### Task 6: Build a Full Stack Application – User Management System

**Description:**

Developed a full-stack User Management System by combining frontend, backend, and database functionalities.

**Key Features:**
- Add user profiles.
- View user details.
- Update existing user information.
- Delete user profiles.
- Connect the frontend interface with backend APIs.
- Retrieve and display data from the database.

**Technologies Used:**
- HTML
- CSS
- JavaScript
- React.js (if used)
- Node.js
- Express.js
- Database / SQL
